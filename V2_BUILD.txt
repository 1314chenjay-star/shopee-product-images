Shopee TinySnow Image Tool V2

Runtime: Windows PowerShell 5.1 compatible
Core mode: EDIT / PRESERVE / LOCALIZE. Existing product images are the primary visual and factual source; TinySnow edits, cleans, localizes, and recomposes existing content rather than freely redesigning products.
Five-image policy: output is always main + detail1 + detail2 + detail3 + detail4. With 5+ usable originals, select five truthful sources; with fewer than five, fill by reusing/recomposing only existing originals and, when necessary, safe generic copy.
Source modes: single_original, recomposed_originals, generic_fill. Every slot records source paths, source indices, fill reason, generic-copy allowlist, and variant-conflict state.
Taiwan localization: source meaning is preserved while readable source text is converted to natural Taiwan Traditional Chinese and common Taiwan ecommerce wording. Existing V4-A.2 unit conversion remains active (for example 2米 -> 2公尺; detail/spec contexts may use equivalent 200公分 without changing numeric meaning). Brand/model/SKU/numeric meaning must not be altered.
Original-content preservation: clearly readable source-image product attributes, functions, dimensions, materials, models, accessories, instructions, and other product-relevant text should be retained and localized where possible. Unclear text is omitted or left visually neutral rather than guessed.
Source seller cleanup: source-store prices, discounts, free-shipping promises, return promises, after-sales promises, limited-time promotions, and other seller-specific transaction claims are removed instead of translated or rewritten into substitute product claims such as 低敏、親膚、安全 or 安心.
Hallucination guard: no new people, scenes, parts, materials, dimensions, quantities, functions, accessories, gifts, certifications, medical/safety claims, or performance claims may be invented. Existing people/scenes may be preserved when present in the source.
Generic fill: safe generic copy is presentation/shopping guidance only. Conditional phrases such as 多色可選／多尺寸可選 are enabled only when structured product data supports the condition.
Multi-variant safety: a source image may retain information visibly belonging to that source/variant, but variant-specific color/material/quantity/accessory/size/model/function must not be generalized to every option. High-conflict fill never recomposes multiple variant sources.
Conflict source routing: for high-variant-conflict products with quantity/bundle-count disagreement, high-risk main/detail4 use a deterministic visual proxy policy. Detail4 prefers a real original with stronger central product structure and less outer scene clutter; this is a center/outer edge-density proxy only and does not claim semantic image recognition.
Conflict text shield: high-risk main/detail4 may use a text-shield reference to preserve product/person/scene structure while preventing direct copying of conflicting source text. detail1-detail3 remain capable of source-text localization.
Deterministic verified overlay: for text-shielded slots TinySnow is instructed to generate a clean text-free visual. Windows PowerShell then overlays only Taiwan-localized common verified facts or safe generic guidance. This prevents source seller promises, variant-only counts, invented replacement claims, and wrong unit-letter icons from becoming final readable text.
No-OCR policy: local preflight does not use OCR and never claims semantic certainty. TinySnow may localize only source text it can clearly perceive; unreadable or conflicting content must not be guessed.
Validation: V4-B validates fixed five-slot completeness, source provenance, legal source modes, source traceability, generic-copy whitelist, conflict source routing, and deterministic overlay behavior. V4-A.3 layout-similarity novelty retries are disabled because faithful source similarity is not itself an error.
Transport profile: API-R3-120S unchanged; max 2 compressed JPEG references; adaptive medium -> low -> 1-reference retry on transport timeout.
Distribution guard: clean package only; no CI workspace/test artifacts or API key; api_v2.ps1 package SHA-256 remains locked to a27d8107b94c7e5d29aa5e170aea1541f7e95cc6cde6a693556d1d0b0b8bdf0f.
START.bat runs UTF-8 BOM normalization and self-check before the menu opens.
