# 蝦皮商品圖片優化工具 V2｜V4-B 新手版

本工具以 Windows 內建 PowerShell 5.1 執行，把一件蝦皮商品的媒體資訊 Excel 製作成固定 1 張主圖與 4 張詳情圖。V4-B 的核心不是重新設計商品，而是「原圖保真編修＋台灣在地化＋不足五張安全補足」。工具不修改原始 Excel，也不建立最終商品 ZIP。

## 開始前

1. 將整個工具放在一般資料夾中，保留 `START.bat`、`README_新手使用說明.txt` 與 `_system` 的相對位置。
2. 雙擊 `START.bat`。啟動程序會設定 UTF-8，並檢查 PowerShell 腳本與必要檔案。
3. 選 **1** 設定 TinySnow API Key；預設 Base URL 是 `https://tinysnow.one/v1`，模型是 `gpt-image-2`。
4. 選 **2** 測試 API。Key 只會存入 Git 忽略的 `_system/config/config.json`，畫面及日誌不顯示完整 Key。

## 新手操作流程

1. 選 **3 匯入蝦皮 Excel**，選擇後台下載的 `.xlsx`。工具直接讀取 XLSX，不需要安裝 Excel、Python 或其他套件。
2. 選 **4 選擇商品**。畫面會列出商品，只要輸入左側短編號，例如 `1`。商品 ID 在程式內始終以文字處理。
3. 選 **5 下載並檢查原圖**。這一步不使用生圖 API 額度，會檢查圖片能否開啟、尺寸、重複檔案、來源風險與多規格衝突，並建立 V4-B 五圖來源計畫。
4. 選 **6 開始優化目前商品**，輸入 `1` 後開始。工具依序輸出 `main`、`detail1`、`detail2`、`detail3`、`detail4`。
5. 選 **7 查看處理進度**；選 **8** 可直接打開「已生成圖片」資料夾。

> 生圖會使用 TinySnow 額度。安全模式一次只處理目前選中的一件商品，固定輸出 5 張成品；API 暫時錯誤會有限重試，不會無限重試。

## V4-B 核心規則

- **原圖優先**：商品外觀、顏色、結構、原圖既有功能文字、材質文字、尺寸規格、型號、配件與使用說明，能清楚辨識時盡量保留並優化，不為了「重新設計」而刪掉。
- **不是自由生成**：原圖沒有的人物、手、使用場景、零件、配件、贈品、顏色、材質、尺寸、數量、功能、認證與功效禁止新增。
- **台灣在地化**：簡體文字改成自然台灣繁體，規格、尺寸、功能標題與說明盡量用台灣賣家常用說法。像 `2米` 顯示為 `2公尺`；尺寸圖必要時可用等值 `200公分`，但不能改變數值意義。
- **避免大陸電商語氣**：例如「宝贝、爆款、神器、厂家直销、一件代发、包邮、秒杀」等詞不應出現在新成品。
- **看不清就不猜**：本地流程沒有 OCR 真值保證。參考圖文字看不清、被遮住、語意衝突時，寧可省略或保留成不可辨識視覺，不猜規格。

## 固定五張與補圖規則

工具固定輸出：

```text
商品ID_main.jpg
商品ID_detail1.jpg
商品ID_detail2.jpg
商品ID_detail3.jpg
商品ID_detail4.jpg
```

來源模式只有三種：

- `single_original`：一張現有原圖一對一保真編修。
- `recomposed_originals`：原圖不足五張時，只把 1～2 張現有原圖的真實內容重新裁切、整理、組合，不創造新商品資訊。
- `generic_fill`：現有內容仍不足時，保留真實商品來源，只允許安全白名單通用文字補充。

原圖超過五張時，工具會選出五個可用來源；剛好五張時原則上一對一優化；少於五張時先使用現有內容重組，再用安全白名單補足。即使只有一張原圖，補圖也必須繼續使用同一真實商品視覺，不可憑空生成另一種商品畫面。

## 安全白名單

可使用的低風險通用文字包含「商品展示、細節展示、選購前請確認規格、商品外觀如圖所示、商品細節如圖所示、圖片僅供參考，請以實際收到商品為準」等。

條件式文字只有資料真的支持才可用：

- 真有多色：`多色可選`
- 真有多尺寸：`多尺寸可選`
- 真有多款式：`多款式可選`
- 真有多規格：`實際規格請依商品選項為準`

白名單也不能拿來虛構功能、材質、尺寸、數量、配件、贈品、認證或功效。

## 多規格商品

某張來源圖若清楚代表某一個規格，可以保留該來源圖本身看得到的內容；但不能把單一規格的顏色、材質、數量、配件、尺寸、型號或功能改寫成所有規格共同具備。

高衝突商品在補圖時不會把不同規格原圖混在一起，避免產生不存在的組合。

## 五張圖角色

- **main**：保留原商品主視覺，做乾淨台灣電商封面整理。
- **detail1**：保留來源圖既有商品重點、功能說明或細節。
- **detail2**：保留來源圖既有結構、局部、配件、包裝或其他可見內容。
- **detail3**：來源圖已有使用方式／情境才保留；沒有就整理原有內容，不自行新增人物或場景。
- **detail4**：優先整理既有尺寸、規格、款式或選購資訊；沒有可靠規格時只使用安全提醒。

V4-B 不再因為「兩張圖版型很像」就強迫重新生成。只要來源真實、五圖完整、來源模式合法、補圖文案安全，版型相似本身不是錯誤。

## 最終輸出

成品直接放在 `START.bat` 同層的 `已生成圖片`：

```text
START.bat
README_新手使用說明.txt
已生成圖片/
  商品ID_main.jpg
  商品ID_detail1.jpg
  商品ID_detail2.jpg
  商品ID_detail3.jpg
  商品ID_detail4.jpg
_system/
```

原圖、來源計畫、分析資料及 checkpoint 留在 `_system/workspace`，它們是續跑與驗證資料，不是最終成品。

## 主選單

1. 設定 TinySnow API
2. 測試 TinySnow API
3. 匯入蝦皮 Excel
4. 選擇商品（只輸入左側編號）
5. 下載並檢查原圖（不花 API 額度）
6. 開始優化目前商品（花 API 額度）
7. 查看處理進度
8. 打開「已生成圖片」資料夾
9. 進階設定
0. 離開

## 常見錯誤

- **401 / 403**：檢查 Key、帳務或模型權限。
- **404**：Base URL 應填到 `/v1`，不要填完整圖片接口。
- **400**：模型或請求參數可能不受支援。
- **429 / 5xx**：工具會有限重試，仍失敗時會保存 checkpoint。
- **Excel 找不到商品**：需要蝦皮媒體資訊表中的商品 ID、商品名稱、主商品圖片及商品圖片欄位。

完整錯誤日誌位於 `_system/logs`。續跑狀態位於 `_system/workspace/checkpoints`。請勿刪除 `_system` 或只移動 `START.bat`。
