# 蝦皮商品圖片優化工具 V2｜新手版

本工具以 Windows 內建 PowerShell 5.1 執行，把一件蝦皮商品的媒體資訊 Excel 製作成 1 張主圖與 4 張詳情圖。工具不修改原始 Excel，也不建立 ZIP。

## 開始前

1. 將整個工具放在一般資料夾中，保留 `START.bat`、`README_新手使用說明.txt` 與 `_system` 的相對位置。
2. 雙擊 `START.bat`。啟動程序會設定 UTF-8，並檢查 PowerShell 腳本與必要檔案。
3. 選 **1** 設定 TinySnow API Key；預設 Base URL 是 `https://tinysnow.one/v1`，模型是 `gpt-image-2`。
4. 選 **2** 測試 API。Key 只會存入 Git 忽略的 `_system/config/config.json`，畫面及日誌不顯示完整 Key。

## 新手操作流程

1. 選 **3 匯入蝦皮 Excel**，選擇後台下載的 `.xlsx`。工具直接讀取 XLSX，不需要安裝 Excel、Python 或其他套件。
2. 選 **4 選擇商品**。畫面會列出商品，您只要輸入左側短編號，例如 `1`，不必輸入很長的商品 ID。商品 ID 在程式內始終以文字處理。
3. 選 **5 下載並檢查原圖**。這一步不使用生圖 API 額度，會檢查圖片能否開啟、尺寸、比例、重複檔案，並執行 V4-A.2 Reference Safety 本地風險排序。
4. 選 **6 開始優化目前商品**，確認商品後依畫面提示輸入 `1`。工具只在輸入 `1` 時開始，並依序生成 `main`、`detail1`、`detail2`、`detail3`、`detail4`。
5. 生成畫面會即時印出目前步驟；回到選單後也可選 **7 查看處理進度**，查看商品、狀態、總進度、成功/失敗圖片數、最後更新時間與最後日誌。
6. 選 **8 打開「已生成圖片」資料夾**。資料夾不存在時會自動建立。

> 生圖會使用 TinySnow 額度。安全模式一次只處理目前選中的一件商品，固定最多 5 張成品；遇到可重試的暫時錯誤最多嘗試 3 次，不會無限重試。

## 最終輸出

成品一律直接放在 `START.bat` 同層的 `已生成圖片`，不建立商品子資料夾：

```text
START.bat
README_新手使用說明.txt
已生成圖片/
  商品ID_main.jpg
  商品ID_detail1.jpg
  商品ID_detail2.jpg
  商品ID_detail3.jpg
  商品ID_detail4.jpg
_system/
```

原圖、分析資料及 checkpoint 是續跑所需的內部工作資料，留在 `_system/workspace`；它們不是最終成品。工具不會建立或自動打包 ZIP。

## 六步進度

1. 原圖下載完成
2. 原圖分析完成
3. 主圖完成
4. 詳情圖 1～2 完成
5. 詳情圖 3～4 完成
6. 成品整理完成

第 7 項會顯示目前選中的商品 ID、商品名稱、目前狀態、`0/6` 到 `6/6`、已生成圖片數、失敗圖片數、最後更新時間及最後一條日誌。生成中的主畫面也會輸出目前正在下載、分析或生成哪一張圖片。

## 圖片規則

- **主圖**：商品夠大且一眼可辨、有明確主標題與真實短賣點；多規格商品若沒有共同規格資訊，寧可少字或留白，不把單一規格寫成全商品事實。
- **detail1**：核心資訊總覽；不得只替主圖換背景。
- **detail2**：優先呈現商品本體結構與可見細節。配件、贈品、內含物只有進入已驗證白名單時才可寫成隨附內容。
- **detail3**：使用方式與合理情境；不得自行加入運動效果、醫療效果或性能提升。
- **detail4**：只有已驗證白名單已有數值時才做尺寸／規格文字；資訊不足時改做保守選購提醒，絕不猜測數字。
- 程式會以低解析灰階區塊、邊緣與亮度分布比較整組圖片的畫面骨架。詳情圖版型過度相似時只重生該 slot，最多重生 2 次，不會共用或消耗 API transport retry 次數。
- 所有文字一律是自然的台灣繁體中文。禁止捏造尺寸、材質、功能、配件、認證、保固、贈品、型號或數據，也禁止「爆款、神器、高端、秒殺、抖音同款」等中國大陸電商詞。

## V4-A.2 Reference Safety

- 商品所有可用原圖都會先參與本地 Reference Safety 分析；不是只看主圖與第一張詳情圖。
- 本地分析會依畫面邊緣密度、外圍高頻訊號、重複圖與多規格衝突等做風險排序，再為每個成品 slot 選最安全的參考子集。
- 真正送給 TinySnow 的參考圖仍遵守 API-R3-120S：最多 2 張；跨規格衝突高的商品預設只送最安全的 1 張。
- 高衝突參考圖會使用低解析安全代理圖，保留商品輪廓與基本結構，同時降低參考圖既有品牌字、促銷字、規格字被模型重新畫出的機率。
- 成品採「逐字白名單」：可辨識的中文、英文、數字、單位、品牌或 Logo 文字，只能來自已驗證事實與允許的低風險文案。商品表面未驗證印字要求省略或處理成不可辨識紋理。
- **重要限制：Reference Safety 沒有 OCR，也不宣稱能理解每張原圖上的文字語意。** 它是本地視覺風險代理＋Shopee 結構化規格白名單＋Prompt 隔離的組合防護，不是百分之百語意審圖。因此資訊不足時仍以少寫、不猜為原則。

## 常見錯誤

- **401 / 403**：請檢查 Key、帳務或模型權限。
- **404**：Base URL 應填到 `/v1`，不要填完整圖片接口。
- **400**：模型或請求參數可能不受支援。
- **429 / 5xx**：工具會有限重試，仍失敗時會保存 checkpoint。
- **Excel 找不到商品**：需要蝦皮媒體資訊表中的商品 ID、商品名稱、主商品圖片及商品圖片欄位。

完整錯誤日誌位於 `_system/logs`。續跑狀態位於 `_system/workspace/checkpoints`。請勿刪除 `_system` 或只移動 `START.bat`。
