TinySnow Coupang 數據採集工具 V1

用途：只處理 Coupang WING 本地數據採集，不包含蝦皮圖片功能。

使用方式：
1. 解壓縮整個資料夾。
2. 雙擊 START.bat。
3. 選 1 開啟 WING 專用瀏覽器。
4. 第一次使用時自行登入 Coupang WING。
5. 在專用瀏覽器中打開需要採集的商品、訂單、數據分析等頁面。
6. 回工具選 2 採集目前已開啟的 Coupang 頁面。
7. 選 3 打包最新採集資料。

安全原則：
- 不讀取或保存帳號密碼。
- 不修改 Coupang Open API。
- 不影響目前綁定易客的物流串接。
- 本機登入狀態與採集資料保留在 _system\workspace\coupang。
